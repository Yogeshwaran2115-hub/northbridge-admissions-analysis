# Northbridge University Admissions Analysis

## Project Overview

This project analyses admissions data from two recruitment sources using Python and machine-learning techniques.

## Objectives

- Load, validate and clean the datasets.
- Conduct exploratory data analysis and visualisation.
- Compare Logistic Regression and Random Forest classification models.
- Examine group-level fairness indicators.
- Discuss limitations, ethical considerations and responsible use.

## Tools

Python, pandas, NumPy, Matplotlib and scikit-learn.

## Notebook

Open `Northbridge_Admissions_Analysis.ipynb` to review the analysis, code, visualisations and model evaluation.

## Responsible Use

The models are intended to support human review rather than make fully automated admissions decisions.
